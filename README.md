The phone battery's last text message to the charger it waited for all day — one spiteful line, written to `/output/entry.txt`. The battery sat at 1% since lunch just to watch its owner panic, and chooses the exact moment the charger finally shows up to die. No sad-battery cliché: the turn is that the death is deliberate, and the sign-off is pure group-chat energy.

## Run it

```sh
python3 main.py
```
